
# Mixed English Lecture -> Egyptian Arabic Handwritten Infographic Prompt Pack  
## Arabic-Dominant + English Handwriting Style Variants (2026)

An upgraded Markdown pack based on the original mixed English lecture prompt set. This version keeps the same core educational purpose, but strengthens the output style so that:

- **Most of the explanation, notes, tips, and study guidance are in Arabic**
- **Important technical terms, formulas, laws, scientific names, and some definitions may remain in English when that is academically appropriate**
- The Arabic explanation can lean naturally toward **clear Egyptian educational phrasing**
- Each prompt now asks for a **different elegant English handwriting/calligraphic style**
- Each prompt also includes this rule:
  - **If an image is attached, imitate the handwriting style in the attached image as closely as possible**
  - **If no image is attached, use the requested handwriting style from the prompt**

This pack is especially useful when:
- the lecture/source file is in English
- you want the final notes to look handwritten and premium
- you want most of the readable explanatory content to be in Arabic
- you still want the original English terminology preserved where needed for study and exams

## Core Style Upgrade for This Version

In every prompt below, the model should follow these language priorities:

1. **Arabic should dominate the page visually**
   - Most explanatory text
   - Most memory hints
   - Most exam notes
   - Most simplifications
   - Most clarifications
   - Most side comments

2. **English remains where academically useful**
   - scientific terms
   - formulas
   - laws
   - names of processes
   - technical headings when needed
   - exact terminology from the lecture
   - some official definitions if they are best preserved in English

3. **Natural mixed style**
   - Do not make the result English-only
   - Do not make the result fully formal Arabic if the mixed academic style helps more
   - Let the page feel like a real student's handwritten bilingual study notebook:
     - Arabic explanation first
     - English term kept where needed
     - simple, memorable, exam-friendly presentation

## Global Non-Negotiable Rules

Use these rules in all variants:

- The source file may be in English.
- The final output must remain **strictly faithful to the uploaded file**.
- Do **not** omit essential ideas.
- Do **not** add external facts that do not appear in the source.
- Make the output look like **real handwritten study notes**.
- Keep the layout optimized for **exam review and fast memorization**.
- Most visible explanation should be in **Arabic**, preferably natural Egyptian educational style when suitable.
- Preserve important lecture terms in **English** when needed for understanding and exam alignment.
- If a formula, law, symbol, scientific name, or official concept appears in English in the source, keep it in English whenever that improves academic clarity.
- The handwritten result should feel beautiful, readable, and human, not like sterile printed typography.
- If there is an attached reference image, imitate the handwriting feel and visual rhythm of that image as closely as possible without changing the core study-note goal.
- If there is **no** attached reference image, use the specific handwriting style requested inside the selected prompt.

## Font / Script Direction Rules

Because image models may not support exact named font files, phrase the instruction like this:

- Do **not** ask for a literal desktop font file.
- Ask for a **visual handwriting style** inspired by:
  - elegant English cursive
  - French notebook cursive
  - connected looped penmanship
  - compact academic handwriting
  - slanted school-script handwriting
  - semi-calligraphic handwritten Latin notes
  - narrow quick-note handwriting
  - soft ink-pen cursive
  - monoline handwritten script
  - handwritten board-notes style

For Arabic:
- keep the writing readable and close to human study notes
- use a style inspired by common readable Arabic writing forms such as:
  - Naskh-like clarity
  - Ruq’ah-like speed
  - Diwani-like elegance for selected headings
  - Thuluth-inspired heading drama only when readable
- never let the decorative style harm readability

# MASTER PROMPT — Arabic-Dominant Premium Mixed Version

```text
Transform the provided English lecture or source file into a handwritten-style educational infographic using an Arabic-dominant mixed study-note style by following these guidelines:

1. Page Layout and Visual Appearance
- Background: Present the material on A4 notebook paper with horizontal lines, similar to a student's handwritten study notebook.
- Handwritten Style: Make the writing feel natural, slightly imperfect, human, and handwritten.
- If there is an attached reference image, imitate the handwriting style, rhythm, and overall handwritten feel in that image as closely as possible.
- If there is no attached image, use a premium readable mixed handwriting style:
  - Arabic handwriting inspired by clear handwritten Naskh/Ruq’ah classroom notes
  - English handwriting inspired by elegant academic cursive with a soft French-study-notebook feel
- Organization: Arrange the information in clear, brief bullet points with enough spacing for comfortable study and quick revision.

2. Language Output Style
- Most of the explanation, notes, side comments, simplifications, and revision-friendly content must be in Arabic.
- You may let the Arabic lean toward natural Egyptian educational explanation when that improves clarity and memorization.
- Keep technical terms, formulas, laws, topic names, scientific names, and core lecture terminology in English whenever academically appropriate.
- The result must feel organized and intentional, not random language switching.
- Preserve the exact academic meaning from the source file.

3. Color-Based Organization
- Blue Pen: Use for explanations, ordered steps, and descriptive content.
- Red Marker (Bold): Use for main titles, section headings, and formal definitions.
- Yellow Highlighter: Highlight essential terms, important formulas, final answers, and key conclusions.

4. Visual Elements
- Add simple hand-sketched diagrams, charts, mini concept maps, labeled arrows, and process flows where useful.
- Add handwritten emphasis such as rough circles, underlines, side marks, brackets, and arrows.
- Decorate the margins with subtle hand-drawn doodles that fit the lecture topic and keep a real notebook feel.

5. Exam-Oriented Notes
- Clearly mark content that is important for exams.
- Add small note boxes or bubbles such as:
  - Exam Tip
  - Common Error
  - Memory Hint
- The labels can remain in English if visually suitable, but the explanation inside should mostly be in Arabic.

6. Accuracy and Reliability
- All information must remain completely accurate and strictly derived from the uploaded file.
- Do not omit essential topics.
- Do not add any information that does not appear in the source.
- Keep English technical terms faithful to the source wherever possible.

Final Result
- The final result should resemble high-quality scanned handwritten study notes.
- Most of the page should feel Arabic in explanation and readability.
- English should remain present mainly for the actual lecture terminology, formulas, laws, and official concepts being studied.
```
