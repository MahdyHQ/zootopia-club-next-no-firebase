# Claude Code + Vercel AI Gateway + Opus 4.7
## دليل عملي للمبتدئين جدًا على ويندوز — باللهجة المصرية

> **هدف الدليل**  
> الدليل ده معمول علشان يساعدك تشغّل **Claude Code** على مشروعك من خلال **Vercel AI Gateway**، وتختار **Opus 4.7** بسهولة، ومن غير لخبطة، وبشرح خطوة خطوة كأنك بتعمل ده لأول مرة.

---

## هتتعلم إيه في الدليل ده؟

بعد ما تخلص الدليل ده، هتكون عارف:

- يعني إيه **Claude Code** أصلًا
- يعني إيه **Vercel AI Gateway**
- تجيب **المفتاح** منين
- تحط الإعدادات **فين**
- تفتح Claude Code **إزاي من داخل مشروعك**
- تختار **Opus 4.7** إزاي
- الفرق بين الإعداد **المؤقت** والإعداد **الدائم**
- معنى كل أمر بتكتبه وفايدته
- أهم الأخطاء اللي ممكن تقابلك وإزاي تفهمها

---

## أولًا: يعني إيه Claude Code؟

**Claude Code** هو أداة برمجية من Anthropic بتشتغل من خلال التيرمنال.  
وظيفته إنه يساعدك في شغل الكود مباشرة من داخل المشروع، زي مثلًا:

- قراءة ملفات المشروع
- شرح الكود
- مراجعة المنطق
- اقتراح إصلاحات
- كتابة كود جديد
- تتبع تدفق الـ auth أو الـ queue أو أي جزء في المنصة

### فكر فيه كأنه:
**مساعد برمجي ذكي شغال جوه فولدر مشروعك نفسه.**

---

## ثانيًا: يعني إيه Vercel AI Gateway؟

**Vercel AI Gateway** هو بوابة وسيطة بين Claude Code وبين الموديل.

بدل ما Claude Code يكلم Anthropic مباشرة، يخلي الطلب يعدّي الأول على Gateway.  
وده بيديك مميزات زي:

- مراقبة الاستخدام
- تتبع الترافيك والتوكنز
- رؤية أوضح للطلبات
- تحكم أفضل في مفاتيح الوصول
- توحيد طريقة الوصول للموديل

### فكر فيه كأنه:
**بوابة مراقبة وتوجيه ذكية واقفة بين البرنامج وبين الموديل.**

---

## ثالثًا: الإعدادات دي تخص إيه بالضبط؟

دي نقطة مهمة جدًا.

الإعدادات اللي هنعملها هنا تخص **Claude Code نفسه**، مش إعدادات Next.js الخاصة بموقعك.

يعني:

- **مش** هنحطها في `NEXT_PUBLIC_*`
- **مش** هنحطها في `.env.local` الخاص بتطبيقك علشان الموقع يستخدمها
- **مش** هنربطها بالكود الفرونت بتاع المنصة

إحنا هنستخدمها علشان **برنامج Claude Code** يشتغل على مشروعك بالطريقة الصح.

# تجهيز البداية

## الخطوة 1: تثبيت Claude Code

افتح **PowerShell** واكتب:

```powershell
irm https://claude.ai/install.ps1 | iex
```

### الأمر ده بيعمل إيه؟

| الجزء | معناه |
|---|---|
| `irm` | يجلب محتوى من الإنترنت |
| `https://claude.ai/install.ps1` | سكربت التثبيت |
| `iex` | ينفذ السكربت بعد تنزيله |

### فايدته
الأمر ده بيقوم بتثبيت **Claude Code** على جهازك.

### بعد التثبيت
اقفل PowerShell وافتحه من جديد، وبعدها نفّذ:

```powershell
claude --version
```

### معنى الأمر ده
بيفحص هل Claude Code اتثبت ولا لا.

### لو ظهر رقم إصدار
يبقى التثبيت ناجح.

---

## الخطوة 2: التأكد من وجود Git for Windows

نفّذ:

```powershell
git --version
```

### ليه ده مهم؟
لأن Claude Code على ويندوز محتاج **Git for Windows** علشان يشتغل بشكل طبيعي لو إنت شغال Native على ويندوز.

### لو ظهر رقم إصدار
تمام.

### لو ما ظهرش
ثبّت **Git for Windows** الأول، وبعدها ارجع كمل.

---

## الخطوة 3: إنشاء Vercel AI Gateway API Key

ادخل على **Vercel Dashboard**، وبعدها:

1. افتح **AI Gateway**
2. أنشئ **API Key** جديد
3. انسخ المفتاح وخليه معاك

### المفتاح ده فايدته إيه؟
ده المفتاح اللي هيخلي Claude Code يتكلم مع **Vercel AI Gateway**.

### مهم جدًا
**ما تحفظش المفتاح في GitHub**، وما تحطوش في ملفات هترفعها على الريبو.

# التنفيذ العملي على المشروع

## الخطوة 4: افتح PowerShell داخل مجلد مشروعك

مثال:

```powershell
cd C:\zootopia-club-next
```

### معنى الأمر ده
بينقلك جوه فولدر المشروع.

### فايدته
لما تفتح Claude Code من هنا، هيشتغل على الملفات الموجودة في نفس المجلد ده.

---

## الخطوة 5: ضبط متغيرات البيئة المؤقتة للجلسة الحالية

الصق الأوامر دي في PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL="https://ai-gateway.vercel.sh"
$env:ANTHROPIC_AUTH_TOKEN="ضع_هنا_مفتاح_Vercel_AI_Gateway"
$env:ANTHROPIC_API_KEY=""
$env:ANTHROPIC_MODEL="claude-opus-4-7"
```

### شرح كل سطر

| السطر | وظيفته |
|---|---|
| `ANTHROPIC_BASE_URL` | بيقول لـ Claude Code ابعت الطلبات إلى Vercel AI Gateway |
| `ANTHROPIC_AUTH_TOKEN` | مفتاح الدخول إلى AI Gateway |
| `ANTHROPIC_API_KEY` | لازم يكون فاضي في هذا السيناريو حتى لا يطغى على التوكن الآخر |
| `ANTHROPIC_MODEL` | يحدد الموديل الافتراضي على Opus 4.7 |

### ملاحظة مهمة جدًا
السطر ده مهم جدًا جدًا:

```powershell
$env:ANTHROPIC_API_KEY=""
```

لأن Claude Code بيفحص `ANTHROPIC_API_KEY` أولًا.  
لو لقى فيه قيمة غير فارغة، ممكن يستخدمه بدل `ANTHROPIC_AUTH_TOKEN` ويبوظ التوجيه إلى Gateway.

# هل الإعداد ده مؤقت أم دائم؟

## الإعداد المؤقت — الأفضل للمبتدئ
الطريقة اللي فوق في PowerShell **مؤقتة**.

يعني:

- شغالة في نافذة PowerShell الحالية فقط
- لو قفلت النافذة، المتغيرات دي هتروح

### ليه دي كويسة؟
لأنها:

- سهلة
- آمنة
- ما بتلخبطش الجهاز كله
- كويسة جدًا للتجربة الأولى

---

## الإعداد الدائم — بعد ما تتأكد إن كل حاجة شغالة

بعد ما تجرب وتلاقي كل شيء تمام، تقدر تعمل إعداد دائم على مستوى Claude Code.

### فين؟
في واحد من الملفين دول:

- `.claude/settings.json`
- `.claude/settings.local.json`

### الفرق بينهم

| الملف | استخدامه |
|---|---|
| `.claude/settings.json` | إعدادات مشتركة للمشروع |
| `.claude/settings.local.json` | إعدادات شخصية محلية، والأفضل للأسرار والتجارب |

### مثال إعداد دائم

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://ai-gateway.vercel.sh",
    "ANTHROPIC_AUTH_TOKEN": "ضع_هنا_مفتاح_Vercel_AI_Gateway",
    "ANTHROPIC_API_KEY": "",
    "ANTHROPIC_MODEL": "claude-opus-4-7"
  }
}
```

### نصيحتي لك
لو أنت مبتدئ، **ابدأ بالمؤقت أولًا**.  
ما تنقلش للإعداد الدائم إلا بعد ما تتأكد إن كل حاجة شغالة تمام.
